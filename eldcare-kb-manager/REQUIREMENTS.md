# 家庭影院 · 需求分析

> 整理时间：2026-09-05
> 适用对象：老张家用家庭影院
> 当前现状参考：`pi05应用盘点报告-2026-09-05.md`

---

## 1. 一句话定位

**让家里（局域网 + Tailscale VPN）所有设备——电视盒、手机、平板、PC——都能方便地浏览、搜索、播放、整理老张家收藏的电影 / 纪录片 / 儿童内容，且尽量减少下载和整理的人工维护。**

---

## 2. 用户画像

| 角色 | 主要场景 | 关注点 |
|------|---------|--------|
| **老张**（管理员） | 找片源、整理、下载、远程维护 | 自动化、可视化、可控、节省时间 |
| **家人长辈**（播放者） | 客厅电视 / 床头平板看老电影 | 大按钮、简洁、自动续播 |
| **小孩**（观众） | 看动画、短片 | 儿童区分类、家长控制 |
| **客人**（临时） | 投屏 / 推送视频 | 临时权限、易访问 |

---

## 3. 功能需求

### 3.1 影片管理（P0）

- **入库**：自动扫描指定目录、识别文件名、年份、清晰度、来源标签、字幕
- **元数据**：对接 TMDB（海报、简介、演员、类型、评分）；断网 fallback 本地缓存
- **分类**：自动分类（动画 / 4K / 院线 / 纪录片 / 儿童 / 短片）+ 手动分类 + 标签 + 收藏夹
- **搜索**：标题 / 演员 / 类型 / 年份 / 文件名 / 标签
- **统计**：总片数、总容量、分类分布、最近添加、最近播放

### 3.2 播放（P0）

- **网页播放**：浏览器内嵌 HTML5 player（HLS / MP4 原生 / MKV 转封装 / Range 请求）
- **多端**：手机 / 平板 / 桌面浏览器自适应，电视端需大字体、遥控友好
- **断点续播**：记录每人每片观看进度
- **字幕**：外挂字幕自动加载、字体/位置/大小可调、字幕在线下载（射手网/OpenSubtitles）
- **音轨切换**：多音轨电影支持切换
- **画音同步**：拖动进度条不卡顿

### 3.3 下载（P0）

- **磁力 / 种子**：BT 下载（中继服务器可分担流量）
- **HTTP 直链**：直链下载
- **任务管理**：队列、并发控制、限速、失败重试
- **入库联动**：下载完成后自动入库 + 自动刮削元数据
- **公版片源**：内置 Internet Archive / Blender 开放电影 / 国语配音老电影等合法源

### 3.4 移动端体验（P1）

- **PWA 安装**：手机/平板添加到主屏后像原生 APP
- **投屏**：DLNA / AirPlay 推送至电视（可选插件）
- **远程遥控**：手机端可控制本机播放（"客厅看片，厨房暂停"）
- **下载任务通知**：完成推送手机

### 3.5 多用户 & 家长控制（P1）

- **多账户**：每人独立播放历史、收藏、追剧
- **儿童模式**：默认只显示动画/儿童区，无搜索功能
- **观看时长限制**：小孩账户单次播放 30 分钟提示休息

### 3.6 数据安全（P1）

- **本地优先**：所有数据本地存储（SQLite），不上传云
- **备份**：movies.db 每日自动快照至外置硬盘 `/mnt/ztv/backups/`
- **刮削缓存**：TMDB 数据本地缓存，断网仍可浏览

### 3.7 自动化 & AI（P2）

- **推荐**：基于观看历史推荐相似影片
- **自动追新**：订阅的演员/导演新片自动下载（需 BT 源）
- **语音控制**：客厅场景下"播放最近添加的纪录片"
- **字幕自动生成**：本地 whisper.cpp 给无字幕视频生成字幕

## 4. 非功能需求

| 项 | 要求 |
|------|------|
| **首屏加载** | ≤ 2s（局域网） |
| **滚动列表** | 60fps（1000 部内） |
| **播放起播延迟** | ≤ 3s（局域网，MP4） |
| **可并发用户** | 至少 4 路同时播放 |
| **可用性** | 服务 7×24，断电自启 |
| **存储容量** | 支持 ≥ 10TB 媒体库 |
| **客户端兼容** | Chrome 100+, Safari 15+, Edge 100+, 微信内置, TV 内置浏览器 |
| **扩展性** | 模块化，新功能以插件形式接入 |

## 5. 现状痛点（基于 if-pi05 盘点）

| 痛点 | 来源 | 严重度 |
|------|------|--------|
| 单机 Flask、SQLite，未做横向扩展 | kb_manager | 🟡 中 |
| 自动下载任务每次只下到中继、再 HTTP 拉回来 | auto_download.py | 🟡 中（多一跳） |
| HomeTheater（Windows 本机）与 kb_manager（pi05）数据完全独立 | pi05 vs HomeTheater | 🔴 高（重复系统） |
| 元数据来源单一（TMDB），无本地 fallback | app.py | 🟡 中 |
| 无 PWA / 远程遥控 / 多用户 | app.py | 🟡 中 |
| nms-agent 与 mcp_edge 监控未启，远程无健康度 | pi05 | 🔴 高 |
| 移动端体验差（无 PWA） | HTML 模板 | 🟡 中 |

---

## 6. 边界 & 不做

- **不做**：商业 DRM 内容播放（Netflix / Disney+ 等）；大型多人点播同步观看；专业级剪辑导出（交给剪映）。
- **弱化**：硬件转码（用客户端解码为主，转码为辅）。
- **未来考虑**：CDN 加速（局域网够用 5 年）；多机房部署（家庭场景不需要）。

---

## 7. 验收标准（V1.0 MVP）

1. ✅ 至少 100 部电影能稳定入库 + 分类 + 搜索
2. ✅ 手机浏览器能流畅播放 ≥ 2 路同时
3. ✅ 一键从磁力/HTTP 添加下载 → 完成自动入库
4. ✅ 断电重启后服务自动恢复
5. ✅ 局域网 + Tailscale 外网均能访问
6. ✅ 本机 / pi05 两个数据源最终打通（DB 同步或主备）
